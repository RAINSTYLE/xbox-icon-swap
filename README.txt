XBOX ICON SWAP — иконки Xbox вместо PlayStation в PC-портах игр с PS4
=====================================================================

Поддерживается: EA SPORTS UFC 3 (нативный порт, CUSA06534).
Проверено только на нативном PC-порте UFC 3 (UFC-3-PS4-PORT-LINUX-WINDOWS,
обновление 1.14). Другие порты и версии не проверялись.

Страница проекта: https://github.com/RAINSTYLE/xbox-icon-swap

КАК ПОЛЬЗОВАТЬСЯ
1. Закройте игру и её лаунчер (UFC3.exe).
2. Запустите XboxIconSwap.exe.
3. Папка игры находится сама (из настроек лаунчера порта). Если нет —
   нажмите «Обзор...» и укажите папку, где лежат eboot.bin и databigs.
4. Нажмите «Установить иконки Xbox». Занимает несколько секунд.
5. Запускайте игру как обычно.

Вернуть всё как было: кнопка «Вернуть оригинальные». Файл игры
восстанавливается байт в байт.

ЧТО МЕНЯЕТСЯ
54 текстуры в databigs\inxp_ui_40.big и кнопки меню в Scaleform-файлах
samplefedata.swf и tin.swf (в inxp_ui_40.big и patch_inxp900.big):
  ✕ ○ △ □                 →  A B Y X (во всех стилях: цветные, белые, крупные)
  L1 R1 / L2 R2           →  LB RB / LT RT (и парные «L1 R1», «L2 + R2»)
  L3 / R3                 →  LS / RS
  OPTIONS                 →  ≡ MENU
  тачпад                  →  кнопка View
  кнопка PS               →  кнопка Xbox
  силуэт DualShock 4      →  силуэт геймпада Xbox (иконка выбора устройства)
  схемы в меню управления →  подписи LT/LB/RT/RB, VIEW/MENU и цветные Y/B/A/X
  кнопки главного меню    →  родные Xbox-кнопки EA (они есть в файлах игры,
                              программа просто показывает их вместо PS-версий)

КАК ЭТО РАБОТАЕТ И ПОЧЕМУ БЕЗОПАСНО
- Новые текстуры дописываются в конец архива; старые данные не трогаются.
  В таблице архива меняются только ссылки на изменённые файлы.
- Рядом с каждым изменённым архивом создаётся файл *.xboxicons.bak:
  в нём исходная таблица и исходный размер файла. По нему делается откат.
  Не удаляйте его, пока установлены иконки Xbox.
- Повторная установка сначала откатывает прошлую, файл не растёт.
- Если игра обновится или вы замените файлы игры — сначала нажмите
  «Вернуть оригинальные» (или удалите .bak вместе с заменой файла).

СВОИ ИКОНКИ
В программе нет файлов игры: при первом запуске она сама рисует иконки
Xbox из текстур вашей копии игры (пара секунд).
Все иконки — обычные PNG в папке Icons\UFC3\inxp_ui_40\...
Удалите эту папку, чтобы программа нарисовала их заново.
Их можно перерисовать в любом редакторе (с прозрачностью) и снова нажать
«Установить». Размер желательно сохранить — иначе картинка будет растянута.

ЗАПУСК БЕЗ ОКНА (для ярлыков/скриптов)
  XboxIconSwap.exe --install "E:\Games\EA Sports UFC 3"
  XboxIconSwap.exe --restore "E:\Games\EA Sports UFC 3"
Журнал пишется в XboxIconSwap.log рядом с программой.

ТРЕБОВАНИЯ
Windows 10/11 x64 и .NET 8 Desktop Runtime (если не установлен, Windows
сама предложит скачать его при первом запуске).

ПРОБЛЕМЫ
- «Файл игры занят» — закройте игру и лаунчер.
- «Нет доступа» — запустите программу от имени администратора.
